# Public datasets

Reproducible bench inputs. **TCIA only**. Private/anonymized data is never used.

## Sources

| Dataset | Modality | Approx. shape | URL |
|---|---|---|---|
| NSCLC-Radiomics | Chest CT | 512×512×~300 | https://www.cancerimagingarchive.net/ |
| CT-ORG | CT (140 scans, organ labels) | varies | https://www.cancerimagingarchive.net/collection/ct-org/ |
| TCGA-GBM | Brain MRI (T1, T2, FLAIR) | varies | https://www.cancerimagingarchive.net/ (browse) |

## Layout

After preprocessing each dataset lives under its own subdirectory:

```
public/datasets/
  phantom-32/             # synthetic, generated by tools/preprocess phantom
    volume.raw
    manifest.json
  nsclc-001/              # real DICOM, ingested via tools/preprocess dicom
    volume.raw
    manifest.json
```

## Storage

Raw volumes are big (NSCLC ≈ 150 MiB). They are **not** committed directly.

- Synthetic phantoms (≤ a few MiB) — committed via Git LFS.
- Real TCIA volumes — committed via Git LFS once we have credentials wired up.
- Until then, `.raw` and `.json` under `datasets/**` are gitignored; users
  generate them locally with `tools/preprocess`.

## Citation

Every benchmark publication must cite the TCIA collection used. Format:

> Aerts H. et al., NSCLC-Radiomics, The Cancer Imaging Archive (2014). DOI: …
